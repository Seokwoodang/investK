# InvestK 인스타그램 자동 게시 전략

> 계정: **@invest___k** · 도메인: **investk.app** · 완전 자동화(수동 업로드 없음)
> 최종 업데이트: 2026-07-26 (v0.42.0)

이 문서는 인스타 게시 **일정 + 콘텐츠 + 성장 전략**의 단일 기준점이다.
코드/워크플로를 바꾸면 여기도 같이 갱신한다.

---

## 1. 목표 · 포지셔닝

- **한 줄 정체성**: "매일 아침·저녁, 30초로 끝내는 시장 브리핑"
- **목표**: 팔로워 유입 → 프로필 링크(investk.app) 클릭 → 사이트 방문/가입
- **톤**: 전문적이지만 쉽게. AI 티 안 나게. 숫자는 정확하게(틀린 숫자 = 신뢰 즉사).
- **핵심 KPI**: 저장(save) · 프로필 방문 · 링크 클릭. 좋아요보다 **저장/공유**가 도달을 키운다.

## 2. 게시 일정 (KST 기준)

### 상시 스케줄

| **07:30** | 아침 뉴스(밤사이 미국·글로벌) | 캐러셀(커버+뉴스3+마무리) | **매일** | 없음 |

| **20:00** | 저녁 뉴스(오늘 국내·마감) | 캐러셀(커버+뉴스3+마무리) | **매일** | 없음 |

**결과: 하루 3~4회, 하루도 안 비는 편성.** 주말엔 일일 시황(스킵) 대신 주간리뷰·캘린더·뉴스(아침·저녁)가 채운다.

### 뉴스 하루 2회 (중복 방지)

- **아침(slot=am)**: 밤사이 미국·글로벌 뉴스. `🌅 밤사이 투자 뉴스`.
- **저녁(slot=pm)**: 오늘 국내·마감 뉴스. `📰 오늘의 투자 뉴스`.
- **중복 차단**: 아침에 후보로 쓴 제목을 KV(`news:am:{날짜}`)에 기록 → 저녁은 그걸 제외하고 선별.
  캐시 키도 슬롯별(`news-cards:{날짜}:{am|pm}`)로 분리. 뉴스 풀은 하루 4회 갱신(00·06·12·18 KST)돼 저녁엔 새 뉴스가 충분.

## 3. 콘텐츠 종류

| type | 카드 | 데이터 소스 | 설명 |
|---|---|---|---|
| `daily` | cover/kr/global/crypto/outro | getCardData (브리핑 캐시) | 오늘의 지수·코인·환율 총정리 |
| `news` | news-cover/news-N/news-outro | getNewsCardData (AI 요약) | 뉴스 3건 카테고리·팩트3·왜중요 |
| `week` | week-cover/week-detail/week-outro | getWeekReviewData | 한 주 총정리(지수 주간등락·최고/부진·요약) |
| `calendar` | cal-cover/cal-1/cal-2/cal-outro | getCalendarCardData | 이번 주 경제 일정, 고영향 강조 |
| `value` | value-cover/value-N/value-outro | getValueCardData (국내/해외 로테이션) | PER·PBR·ROE·배당 저평가 TOP5 |
| `term` | term-cover/def/example/tips/outro | getTermCardData (주간 로테이션) | 투자 용어 1분 교육 |
| `breaking` | breaking | getBreakingCardData (야후 실시간) | 지수±3%/VIX/BTC±5% 급변동 속보 |

카드 렌더: `/api/card/[type]` (Satori/ImageResponse, 1080×1350 4:5, 다크).
데이터 조립: 전부 `src/server/cardData.ts`.

## 4. 릴스 전략 (도달 확대의 핵심)

- **왜 릴스**: 인스타 도달의 대부분은 릴스. 캐러셀은 저장/심화, 릴스는 신규 유입.
- **현재 자동 릴스**:
  - **데일리 릴스** (12:30 KST): 브리핑 카드 → ffmpeg로 9:16 세로 영상 합성(zoompan·페이드·앰비언트 오디오) → Supabase 서명 URL 업로드 → `media_type=REELS` 게시.
  - **속보 릴스**: 급변동 감지 시 즉시.
- **한계**: 트렌딩 오디오는 API로 못 붙임(수동만 가능) → 기본 앰비언트 사용.
- **개선 여지(TODO)**:
  - [ ] **주말 릴스**: 데일리 릴스가 신선도 게이트로 주말 스킵됨 → 토요일 **주간리뷰를 릴스로도** 내보내면 주말 도달 유지.
  - [ ] 릴스 커버(썸네일) 최적화, 훅 문구 첫 1초 강화.
  - [ ] 트렌딩 오디오는 주 1~2회 수동으로 얹는 것 검토.

## 5. 신선도 게이트 (주말/휴장 중복 방지)

- **문제**: 장 안 여는 날 `type=daily`가 어제와 똑같은 숫자로 게시됨.
- **해결**: 지수 마지막 체결시각(`regularMarketTime`)을 키로 KV(`ig:daily:{carousel|reel}:key`)에 저장.
  새 시장 데이터 없으면(키 동일) **게시 스킵**.
- **수동 강제**: `?force=1`.
- **속보도 동일 취지**: `isLive`(최근 3시간 내 체결)인 지수/VIX만 감지 → 주말 스테일값 오탐 방지. BTC는 24/7이라 주말에도 정상.

## 6. 유입 깔때기 (무료·무제한)

인스타 피드 이미지엔 클릭 링크가 안 걸린다. 그래서 3중 장치:

1. **프로필 링크**: bio에 investk.app (유일한 상시 클릭 링크).
2. **자동 첫 댓글**: 게시 직후 봇이 「지표」 안내 댓글 자동 작성.
3. **댓글 → 자동 DM**: 게시물 댓글에 키워드(지표/링크/가격/정보) 남기면
   - 그 사람에게 **DM으로 클릭되는 링크** 발송(인스타에서 링크가 실제 눌리는 유일 경로)
   - 공개 대댓글("DM 보내드렸어요")로 다른 사람 참여 유도
   - `/api/ig/webhook` (ManyChat 불필요, 25명 제한 없음)
   - 루프 방지: 대댓글 무시·본인계정 무시·KV 중복처리 차단

## 8. 성장 팁 (도달 확대)

- **일관성**: 매일 같은 시간 = 알고리즘 신뢰. 주말도 안 비우는 이유.
- **저장 유도**: "저장해두고 보세요"(캘린더) 같은 CTA로 save 유도 → 도달↑.
- **첫 3초/첫 카드**: 커버에 큰 숫자·훅. 넘길 이유를 준다.
- **참여**: 댓글→DM 자동응답이 댓글 수를 올려 노출 가중.
- **워터마크**: investk.app 워터마크로 무단 도용 시에도 브랜드 노출.

## 9. 운영 · 기술 노트

- **토큰**: `INSTA_TOKEN`(graph.instagram.com, 60일 장기). 서버 전용, `NEXT_PUBLIC_` 금지.
  만료 전 `refreshToken()`로 갱신 필요(60일). 본인 계정 게시라 앱 검수 불필요.
- **앱 Live 필수**: Meta 개발자 앱이 "개발모드"면 `me`조차 API access blocked(code 200).
  대시보드에서 개인정보처리방침(investk.app/privacy) 넣고 **Live 게시**해야 함.
- **도메인**: investk.app는 Vercel 등록. ICANN 등록자 이메일 인증 안 하면 정지→DNS 다운.
- **게시 엔드포인트**: `/api/ig/publish?type=…` (Bearer `CRON_SECRET` 또는 `?t=MOCK_FILL_TOKEN`).
  `?dry=1` 미리보기, `?video=<url>` 릴스, `?force=1` 게이트 무시.
- **크론**: GitHub Actions (`.github/workflows/post-instagram*.yml`, `check-breaking.yml`).
