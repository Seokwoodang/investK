# 인스타그램 자동 게시 — 중단됨 (2026-10)

> **이 기능은 코드에서 완전히 제거됐다.** 이 문서는 왜 만들었고 왜 접었는지를 남기기 위한 기록이다.
> 복구가 필요하면 git 히스토리(`v0.64.0` 이전)에서 꺼낼 수 있다.

## 무엇이 있었나

`@invest___k` 계정에 카드뉴스를 완전 자동으로 게시했다. 아침 브리핑·국내/미국 뉴스·
화제의 종목·주간 리뷰·저평가 우량주·투자 용어·급변동 속보를 GitHub Actions 크론이
`/api/ig/publish`로 호출하면, 서버가 카드 이미지를 렌더해 캐러셀로 올리는 구조였다.

제거된 것:
- 워크플로: `post-instagram.yml`, `post-instagram-news.yml`, `post-instagram-stock.yml`,
  `post-instagram-weekly.yml`, `check-breaking.yml`
- 라우트: `/api/ig/publish`, `/api/ig/webhook`, `/api/cron/ig-token`, `/api/cron/breaking`
- 모듈: `src/server/instagram.ts`
- 환경변수: `INSTA_TOKEN`

## 왜 접었나

### 1. 계정 제한 (2026-08-10)

`@invest___k`에 **'사기, 스캠 및 기만적 행위'** 사유로 30일 링크 공유 제한이 걸렸다.

직접적 방아쇠는 스레드 첫 게시로 보인다 — 게시 이력이 0인 계정에서 외부 금융 링크가
붙은 글 2건을 14초 간격으로 자동 발행했다. 자동 분류기 입장에선 스팸 봇의 전형이다.

다만 그 전부터 규정상 위험한 패턴이 돌고 있었다:
- 모든 게시물에 "「지표」 라고 댓글 남기면 링크를 DM으로 보내드려요" 자동 첫 댓글
- 같은 문구를 캡션에도 매 편성 삽입
- 키워드 댓글에 반응해 모르는 사용자에게 링크 DM 자동 발송(webhook)

이건 메타가 engagement bait + 자동 링크 배포로 분류하는 조합이다. 탐지를 피하려고
문구를 회전시키고 응답을 지연시킨 구현이 들어 있었는데, 회피 시도 자체가 위험 신호다.

### 2. 구조적 결함 — 게시 시간이 함수 상한을 넘었다

`publishCarousel`이 카드를 한 장씩 순차 업로드하고 각각 처리 완료를 기다렸다. 6장이면
약 70초가 걸렸는데 `/api/ig/publish`의 상한은 60초(Vercel Hobby)였다. 게시는 성공하는데
호출자는 항상 실패로 받았고, `--retry`가 한 번 더 호출해 같은 글이 두 번 올라갔다.

- 중복 게시 21건(2026-07-30 ~ 08-09)
- 실패율: 브리핑 50%, 화제의 종목 47%, 주간물 30%
- 실패 런 소요가 전부 141~142초로 동일(110s 타임아웃 + 20s 대기 + 재시도)

병렬 업로드로 고쳤지만(v0.60.0), 그 직후 계정 제한이 걸렸다.

### 3. 애초에 유입이 안 됐다

인스타 피드 게시물은 본문에 클릭 가능한 링크를 넣을 수 없다. 유입 경로가
'프로필 방문 → 바이오 링크' 하나뿐이었고, 팔로워 21명·좋아요 평균 0.1에서
사이트 유입은 사실상 0이었다. 하루 7~8회 게시를 3회로 줄여도 달라지지 않았다.

## 남긴 것

- **카드 렌더(`/api/card/[type]`)** 는 유지. 스레드 이미지 게시가 같은 카드를 쓴다.
- **아카이브 적재**는 전용 크론으로 분리했다. 예전엔 인스타 카드 렌더·게시 과정에서
  부수적으로 쌓였는데, 인스타를 제거하면 `/today/{날짜}`·`/review/{주차}` 페이지가
  멈춘다. `/api/cron/archive` + `refresh-archive.yml`이 그 역할을 대신한다.
- **스레드**는 코드가 남아 있으나 자동 편성 cron은 중단 상태다(`post-threads.yml`).

## 재개한다면

같은 실수를 반복하지 않으려면:
- 참여 유도 미끼("댓글 남기면 DM") 금지. 자동 DM 발송 금지.
- 이력 없는 계정에서 외부 링크를 자동으로 쏘지 말 것. 링크 없는 게시로 계정을 먼저
  익히고, 링크는 가끔·수동으로 시작한다.
- 게시 간격을 기계적으로 붙이지 말 것(14초 간격 연속 발행이 방아쇠였다).
