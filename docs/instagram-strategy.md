# InvestK 인스타그램 자동 게시 전략

> 계정: **@invest___k** · 도메인: **investk.app** · 완전 자동화(수동 업로드 없음)
> 최종 업데이트: 2026-08-10 (v0.55.0)

이 문서는 인스타 게시 **일정 + 콘텐츠 + 성장 전략**의 단일 기준점이다.
코드/워크플로를 바꾸면 여기도 같이 갱신한다.

## 1. 목표 · 포지셔닝

- **한 줄 정체성**: "매일 아침·저녁, 30초로 끝내는 시장 브리핑"
- **목표**: 팔로워 유입 → 프로필 링크(investk.app) 클릭 → 사이트 방문/가입
- **톤**: 전문적이지만 쉽게. AI 티 안 나게. 숫자는 정확하게(틀린 숫자 = 신뢰 즉사).
- **핵심 KPI**: 저장(save) · 프로필 방문 · 링크 클릭. 좋아요보다 **저장/공유**가 도달을 키운다.

## 2. 게시 일정 (KST 기준)

### 상시 스케줄

> **[2026-08-10 개편] 평일 7~8회 → 3회로 축소.** 인스타 도달은 팔로워 수가 아니라
> *게시물당 초기 반응률*로 정해진다. 하루 8회는 같은 21명에게 8번 보이면서 반응만
>잘게 쪼갰다. 편성을 줄이고 건당 밀도를 올리는 쪽으로 전환. 릴스는 도입하지 않는다.

| 시간(KST) | 콘텐츠 | 형식 | 빈도 | 게이트 |
|---|---|---|---|---|
| **06:30** | 아침 시장 브리핑 | 캐러셀 5장 | 매일 | 신선도(주말·휴장 스킵) |
| **16:30** | 📈 🇰🇷 국내 화제의 종목 | 캐러셀 4~5장 | 평일 | 조건 미달 시 스킵 |
| **21:30**〔겨울22:30〕 | 🇺🇸 미국 뉴스(개장 1h 전) | 캐러셀 | 매일 | 없음 |
| **월 08:30** | 저평가 우량주 TOP5 | 캐러셀 7장 | 주 1회 | 없음 |
| **수 19:00** | 투자 용어 1분 | 캐러셀 5장 | 주 1회 | 없음 |
| **토 10:00** | 주간 마켓 리뷰 | 캐러셀 3장 | 주 1회 | 없음 |
| **일 19:00** | 주간 경제 캘린더 | 캐러셀 4장 | 주 1회 | 없음 |
| **매 30분** | 급변동 속보 | 단일 이미지 | 감지 시(하루 최대 2) | isLive·중복방지 |

**중단한 편성**(워크플로에 cron이 주석으로 남아 있어 한 줄만 되살리면 복구된다):
05:00 🇺🇸 미국 뉴스(마감) · 08:00 🇰🇷 국내 뉴스(개장 전) · 15:30 🇰🇷 국내 뉴스(마감) · 12:30 🇺🇸 미국 화제의 종목.
국내 지수·환율·코인은 06:30 아침 브리핑이 이미 커버한다.

> 미국 뉴스 시각은 **DST 자동 처리**: 워크플로가 여름·겨울 UTC 크론을 모두 걸고 실행 시 미 동부 오프셋(EDT/EST)을 확인해 유효한 것만 게시. 겨울엔 22:30 KST로 자동 이동.

### 중복 게시 방지 (2026-08-10 수정)

2026-07-30~08-09 사이 **같은 글이 21건 중복 게시**됐다. 원인:

- 캐러셀 게시는 카드 수만큼 인스타 미디어 컨테이너를 만들고 합치느라 **약 70초**가 걸리는데,
  `/api/ig/publish`의 `maxDuration`은 **60초**(Vercel Hobby 상한)다.
- 그래서 게시는 실제로 성공하는데도 호출자(GitHub Actions curl)는 항상 실패로 받고,
  `--retry 1 --retry-delay 20`으로 한 번 더 호출 → **60~80초 간격으로 같은 글이 두 번** 올라갔다.
- `type=daily`만 신선도 게이트가 있어 보호됐고 `news`·`stock`·주간물은 무방비였다.

대책 — `/api/ig/publish`에 **게시 직전 선점하는 멱등 잠금**:
`ig:pub:{type}[:{region}[:{slot}]]:{KST 날짜}` 키를 게시 *전에* 기록한다.
함수가 시간 초과로 잘려도 잠금은 남으므로 재시도는 게시하지 않고 스킵한다.
게시가 명시적으로 실패하면 잠금을 풀어 정상 재시도는 막지 않는다.
`breaking`은 하루 2회라 대상에서 제외(자체 중복 차단 키 사용), `force=1`로 수동 우회 가능.

### 뉴스 = 🇺🇸 미국 개장 1h 전 하루 1회

- 원래 국내·미국 각각 "개장 1h 전 + 마감" 4회였으나 **2026-08-10 축소**로 미국 개장 전 1회만 남겼다.
  - 🇺🇸 미국: 21:30(개장 1h 전, 개장 22:30). **DST 자동**(겨울 22:30, 워크플로가 미 동부 오프셋 확인해 유효 크론만 게시).
  - 🇰🇷 국내(08:00·15:30)·🇺🇸 마감(05:00)은 중단. 코드·캡션·카드는 그대로라 cron만 되살리면 복구된다.
- **썸네일 구분(중요)**: 커버에 **큰 지역 배지 + 지역 강조색**(국내=틸 `#38e0c8`, 미국=바이올렛 `#9B8CFF`).
  숫자·CTA·내부 카드 포인트색도 지역색으로 통일 → 피드 그리드에서 색만 봐도 국장/미장 즉시 구분.
- **지역 순수**: `region=kr`은 kr_stock 탭만, `region=us`는 us_stock 탭만 중요도순 top3. (코인 미편성)
- **중복 차단**: 같은 지역 먼저 나간 제목을 KV(`news:{region}:am:{날짜}`)에 기록 → 나중 회차는 제외.
  캐시 키 `news-cards:{날짜}:{region}:{slot}`. 뉴스 풀은 하루 4회 갱신(00·06·12·18 KST).
  게시 자체의 중복(같은 글 두 번)은 위 "중복 게시 방지"의 멱등 잠금이 담당한다.
- **엔드포인트**: `?type=news&region=kr|us&slot=am|pm`. 캡션 헤더도 지역·세션별(🇰🇷 국내증시 개장 전/마감, 🇺🇸 미국증시 마감/개장 전), 해시태그 지역 맞춤.

### 화제의 종목 (`type=stock&region=kr|us`) — 국내 평일 16:30 · 미국 화~토 12:30

**"추천주"가 아니라 "왜 움직였나" 해설이다.** 이 원칙이 흐려지면 리딩방으로 읽히고 유사투자자문 소지가 생긴다.

- **선정(규칙 기반, 사람 개입 없음)**: 국내 유니버스 → 거래대금 30억↑ · **보통주만**(`^\d{6}$` — `0218L0` 같은 신주인수권·ELW 배제) · ETF/ETN/스팩/우선주 제외 → 거래대금 상위 60 → **화제성 = |등락률| × log10(거래대금)** 최대. |등락| 2% 미만이면 게시 안 함. 최근 7종목은 재선정 제외.
  - log 가중이 핵심: |등락|만 보면 거래대금 수백억짜리 소형주 상한가가 매번 뽑혀 사실상 테마주 소개가 된다.
- **하루 안에서 종목 고정**: 카드 5장이 각각 `getStockCardData()`를 호출하므로 당일 키(`ig:stock:pick:{ymd}`)에 못박는다. 안 하면 **카드마다 다른 종목**이 나온다(실제로 겪은 버그).
- **'왜'는 지어내지 않는다**: 최근 3일 + **종목명이 실제로 박힌** 기사만 쓴다. 네이버 종목뉴스는 전용 기사가 없으면 '마감시황'류를 섞어 주므로, 우리 RSS 랭킹 풀(`page:kr_stock`)에서도 종목명·target 일치 기사를 찾아 합친다. 남는 게 없으면 "뉴스·공시 없이 수급으로 움직였다"고 솔직히 적는다.
- **표시 안 하는 것**: 투자의견(`verdict`), 상승여력. 목표주가는 애널리스트 수와 함께 "증권사 컨센서스 평균"으로만, 없으면 블록 자체를 숨긴다.
- **미국은 선정 방식이 다르다(중요)**: 네이버 US 유니버스는 **일간 등락률이 사실상 비어 있다** — 전 종목의 1.2%만 pct≠0이고 NVDA·AAPL 같은 메가캡도 0.00%, 그 소수마저 신주인수권(`BUI RT WI`)·초소형주다. 그래서 `src/data/usLargeCaps.ts`의 **고정 후보(대형주·인기주 약 100종)**만 두고 등락률은 **Yahoo spark 배치**(`?symbols=…&range=1d`, 심볼 15개씩 — 20개 넘으면 응답이 잘림)로 받는다. 후보가 이미 유동성 검증되어 있어 신뢰할 거래대금 없이 **|등락률| 최대**만으로 고른다. 잡주가 구조적으로 못 들어온다.
- **미국 뉴스는 `.O`·`.N` 둘 다 조회**: 거래소 접미사를 알 수 없어 하나만 쓰면 NYSE 종목(SLB 등)은 뉴스가 0건이 된다. 매칭 키에 **티커도 포함**한다(US 유니버스 이름이 `Slb NV`처럼 엉성해 이름만으론 못 잡음). 표시명도 한글이 없으면 티커를 쓴다.
- **한계**: 관리종목·투자경고 데이터가 없어 거래대금·보통주 필터로만 걸러낸다(국내). 공시(DART)는 국내 전용. 시총은 KR에서 안 잡혀 칸을 숨기고, 거래대금은 US에서 숨긴다.

## 4. 포맷: 카러셀 전용 (릴스 없음)

- **모든 게시물 = 카러셀(넘기는 슬라이드)** 또는 단일 이미지(속보). **자동 재생 영상 릴스는 안 함.**
- **왜 릴스 폐기**: 우리 릴스는 카드 슬라이드쇼 영상이라, 음성·트렌딩 오디오 없는 "정보 전달 릴스"는 어색하고 저품질로 읽힘. 정보성은 넘겨 읽는 카러셀이 맞다. (2026-07-27 결정)
- **음악 관련 핵심 제약**: 인스타는 **API로 음악(라이브러리)을 못 붙임** — 카러셀이든 릴스든. 음악은 **앱에서 사람이 직접 게시할 때만** 추가 가능(저작권 정책). 따라서 "넘기는 슬라이드 + 음악 + 완전자동" 셋 다는 **원천 불가**. 음악을 원하는 게시물은 카드 이미지를 받아 앱에서 수동 게시(+음악)해야 함.
- 제거됨: `post-instagram-reel.yml`, `scripts/make-reel.mjs`, `/api/ig/reel-slot`. (필요 시 git 히스토리에서 복구)

## 5. 신선도 게이트 (주말/휴장 중복 방지)

- **문제**: 장 안 여는 날 `type=daily`가 어제와 똑같은 숫자로 게시됨.
- **해결**: 지수 마지막 체결시각(`regularMarketTime`)을 키로 KV(`ig:daily:{carousel|reel}:key`)에 저장.
  새 시장 데이터 없으면(키 동일) **게시 스킵**.
- **수동 강제**: `?force=1`.
- **속보도 동일 취지**: `isLive`(최근 3시간 내 체결)인 지수/VIX만 감지 → 주말 스테일값 오탐 방지. BTC는 24/7이라 주말에도 정상.

## 6. 유입 깔때기 (무료·무제한)

인스타 피드 이미지엔 클릭 링크가 안 걸린다. 그래서 3중 장치:

1. **프로필 링크**: bio에 investk.app (유일한 상시 클릭 링크).
2. **자동 첫 댓글**: 게시 직후 봇이 「지표」 안내 댓글 자동 작성.
3. **댓글 → 자동 DM**: 게시물 댓글에 키워드(지표/링크/가격/정보) 남기면
   - 그 사람에게 **DM으로 클릭되는 링크** 발송(인스타에서 링크가 실제 눌리는 유일 경로)
   - 공개 대댓글("DM 보내드렸어요")로 다른 사람 참여 유도
   - `/api/ig/webhook` (ManyChat 불필요, 25명 제한 없음)
   - 루프 방지: 대댓글 무시·본인계정 무시·KV 중복처리 차단

## 9. 운영 · 기술 노트

- **토큰**: `INSTA_TOKEN`(graph.instagram.com, 60일 장기). 서버 전용, `NEXT_PUBLIC_` 금지.
  만료 전 `refreshToken()`로 갱신 필요(60일). 본인 계정 게시라 앱 검수 불필요.
- **앱 Live 필수**: Meta 개발자 앱이 "개발모드"면 `me`조차 API access blocked(code 200).
  대시보드에서 개인정보처리방침(investk.app/privacy) 넣고 **Live 게시**해야 함.
- **도메인**: investk.app는 Vercel 등록. ICANN 등록자 이메일 인증 안 하면 정지→DNS 다운.
- **게시 엔드포인트**: `/api/ig/publish?type=…` (Bearer `CRON_SECRET` 또는 `?t=MOCK_FILL_TOKEN`).
  `?dry=1` 미리보기, `?video=<url>` 릴스, `?force=1` 게이트 무시.
- **크론**: GitHub Actions (`.github/workflows/post-instagram*.yml`, `check-breaking.yml`).
